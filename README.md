A program that writes one sharp, funny loading-screen tip (max 200 characters) for stressed developers and AI coding agents to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```

The tip is chosen deterministically from 8 candidates judged against the published judge brief.
